# 数据库设计文档

SQLite 数据库 `backend/xinxifang.db`，12 张表，建表脚本 `backend/init.sql`
（契约来自甲方《sql设计草稿.txt》，conversation_log 扩展 Dify 会话字段）。
首次启动自动建库并写入种子数据（`backend/seed.py`）。

## 表清单

| # | 表名 | 说明 | 关键字段 |
|---|---|---|---|
| 1 | sys_user | 统一用户 | username, password_hash(salt$sha256), real_name, user_type(STUDENT/EMPLOYEE), employee_role(顾问/班主任/管理员), department, contact_info, status(正常/禁用) |
| 2 | student_admin_service | 学生行政服务（请假/考务） | student_id, service_type, start_time, end_time, reason, status(待审批/已通过/已驳回), approver_id |
| 3 | student_psych_profile | 心理健康画像（每生唯一，upsert） | student_id UNIQUE, latest_emotion_tag, emotion_score, last_interaction_time, emotion_history(JSON数组≤50条) |
| 4 | student_psych_alert | 心理预警 | student_id, trigger_reason, risk_level(高/中/低), status(未处理/跟进中/已解除), teacher_id |
| 5 | student_feedback_ticket | 售后反馈工单 | student_id, content, detail, status(待处理/处理中/已解决), solution, is_notified(0/1) |
| 6 | crm_lead | 意向客户 | customer_name, contact_info, background_info, follow_up_history(JSON), status(新增意向/跟进中/已签约/已流失), owner_employee_id |
| 7 | employee_daily_report | 员工日报 | employee_id, report_date, content |
| 8 | student_score | 学生成绩 | student_id, course_name, score(REAL), semester |
| 9 | course_project | 课程与项目 | project_name, category, description(含学费/学制), target_audience |
| 10 | event_lecture | 活动与讲座 | event_name, event_type(线上/线下), start_time, location, max_participants, current_participants |
| 11 | event_registration | 活动报名 | event_id(FK), customer_id, status(已报名) |
| 12 | conversation_log | 对话记录 | user_id, agent_type(student/employee/service), user_input, ai_reply, emotion_tag, dify_conversation_id |

## 关系与约束

- student_admin_service / student_psych_profile / student_psych_alert / student_feedback_ticket / student_score → sys_user（学生）
- student_psych_alert.teacher_id、student_admin_service.approver_id → sys_user（班主任）
- crm_lead.owner_employee_id → sys_user（员工）
- event_registration.event_id → event_lecture（外键启用）
- event_registration.customer_id → crm_lead（访客报名自动创建线索，实现留资留痕）
- conversation_log.user_id：登录用户为 `student_{id}` / `employee_{id}`，访客为 `guest_{session_key}`

## 种子数据（均来自甲方资料）

- 用户 8 个：admin、consultant1/2、teacher1/2、student1(张三)/student2(李四)/student3(许同学)
- 留学项目 9 个：2+2、2+2+1、0.5/1+2、0.5/1+2+1、6+6、9+6、一年制专升本、一年制本升硕、德国双元制
  （description 含真实学费/学制/适合人群，推荐时作为关键信息源，不编造）
- 活动 4 场：含 1 场已满活动（名额 2/2）用于验收 ACC-004 拒绝逻辑
- 客户 4 条：含「许同学」（ACC-003 跟进记录查询用例）
- 成绩 7 条、示例请假 1 条、待处理工单 1 条、心理画像 1 条、日报 1 条

## 维护说明

- 重置数据：停止后端，删除 `backend/xinxifang.db` 后重启（自动重建+种子）。
- 情绪历史仅保留最近 50 条（config.EMOTION_HISTORY_LIMIT）。
- 所有 SQL 参数化执行；NL2SQL 仅白名单表、展示用 SQL 与执行 SQL 分离。
