# 新西方留学服务智能教育服务助手系统

基于 **Dify（大脑）+ FastAPI（手脚）+ SQLite（数据层）** 的多智能体留学服务系统，按《新西方留学服务系统需求规格说明书 V1.0》实现。

## 三大前端板块

| 板块 | 地址 | 说明 |
|---|---|---|
| 官网首页（客户侧） | http://localhost:8010/ | 公司展示、留学项目、智能推荐、活动报名、FAQ、AI 客服、留资 |
| 学生端 | http://localhost:8010/student.html | 请假、成绩、售后反馈、心理关怀聊天、心理画像 |
| 员工与后台 | http://localhost:8010/staff.html | 顾问 / 班主任 / 管理员 三种角色工作台 |

## 心理安全双重兜底

- **在线（Dify）**：学生情绪分支先经「LLM心理风险评估」节点，识别隐晦/隐喻式轻生表达
  （如「从20楼飞到1楼」「想喝硫酸」「开煤气关窗睡觉」「吞整瓶安眠药」），输出情绪标签与分值传后端落库预警。
- **离线/兜底（后端规则）**：`rules/emotion.py` 内置显式高危关键词 + 隐晦高危正则层；
  即使 LLM 给了低分，规则命中仍强制高危（安全优先）。≥70 高危自动写预警并通知班主任。
- **心情打卡分级**：连续 3 天「很低落」→ 关注级（中）；连续 5 天 → 高危（高），同一连续段不重复、可升级。

## 三个 Dify Agent（dify/ 目录，导入即用）

1. **留学生智能管家** `student_agent.yml`：请假 / 记录查询 / 售后反馈 / 心理关怀与高危预警 / 升学咨询
2. **员工业务助手** `employee_agent.yml`：CRM / 日报 / 成绩 / 审批 / 投诉（NL2SQL）/ 新人指南问答
3. **客服与活动** `service_agent.yml`：知识库问答 / FAQ / 画像推荐 / 活动查询报名 / 闲聊

对话上下文：后端按「用户 + Agent」持久化 Dify `conversation_id`，LLM 节点开启记忆窗口，
意图分类结合历史判断（如「那德国呢」「把他状态改为已签约」）。

## 关键业务规则（与需求文档一致）

- 画像推荐：学历定基础池；就业班须中职技校+≥17岁；德国双元制须18-35岁+德语+动手能力强；
  意向加分（就业+5/升学+3/移民+5），上限100，无匹配不编造。
- 心理预警：≥70 高危→写预警表+通知班主任；40-69 关注；<40 正常；画像 upsert，历史保留50条。
- 请假：未传时间从事由兜底解析（今天/明天/后天/明确日期/半天/N天/中文数字）。
- CRM：仅允许 新增意向/跟进中/已签约/已流失，非法状态 400。
- 活动：名额已满 400；成功报名数+1；访客报名自动沉淀 CRM 线索。
- 安全：密码哈希存储；Dify API Key 仅存后端；学生仅能访问本人数据；审批仅班主任/管理员。

## 业务边界

AI 输出为建议，审批与最终决策由人工确认；系统不承担专业心理咨询责任；
高危情绪提示心理援助热线 12356；不含线上支付与合同签署。
